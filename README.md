# TSSM-FCABP: Forced-Choice Asymmetric Betting Paradigm

Turn-key experiment and computational model for:
**A Hierarchical Thermodynamic Taxonomy of Doxastic States** by Ben Ruby (2026).

## What This Project Does
- Models belief, disbelief, and suspension of judgment as energy-constrained states using Active Inference and the Free Energy Principle.
- Runs the Forced-Choice Asymmetric Betting Paradigm (FCABP) with adaptive difficulty locked to ~75% accuracy and EEG/fMRI event markers (`10`, `20`, `31`, `32`, `33`, `40`).
